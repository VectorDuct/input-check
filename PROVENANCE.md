# Provenance

Input Check extracts a bounded text codec and fixed-upstream proxy core from an earlier site-specific gateway maintained for this project owner. The structural checker, configurable marker interface, check-only service and unified CLI are new for this standalone release.

The repository contains only selected source files and synthetic tests. It does not include the former deployment configuration, routes, operational automation, request evidence, credentials or business data. The old wire envelope identifier `OBF-B64/1` is retained for format compatibility and documented openly.

The implementation imports only the Go standard library and has no external Go module dependencies or vendored code. This release is offered under MIT by the project contributors.
